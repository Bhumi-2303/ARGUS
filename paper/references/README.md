# Bibliographic References (`paper/references/`)

This directory houses the machine-readable BibTeX database and human-readable annotated bibliography for all citations supporting the ARGUS research publications.

---

## Directory Inventory

```text
paper/references/
├── README.md                      # Directory guide and reference conventions
├── references.bib                 # Master BibTeX database containing all official paper citations
└── BIBLIOGRAPHY.md                # Human-readable annotated bibliography with DOIs and verification notes
```

---

## Citation Usage

- For LaTeX/BibTeX documents, import [`paper/references/references.bib`](file:///home/bhumi/GitHub/ARGUS/paper/references/references.bib).
- Citation keys strictly match standard academic conventions (e.g., `neto2023ciciot2023`, `sommer2010outside`, `sun2016deep`, `ganin2015unsupervised`).
- No citations or DOI numbers are fabricated.
